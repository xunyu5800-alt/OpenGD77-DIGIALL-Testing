# 普通双段 MD-UV380／MD-UV390 5W＋GPS

使用包名含MD_UV380_UV390_5W_GPS的固件。不能刷入单段MD-380／MD-390；背光PD8、PA选择PC6。
安装与资源检查见[使用说明](USAGE.zh-CN.md)。换固件不会自动修正以前错用10W包生成的本地校准。先备份本机码表与校准，不导入他台校准。

若确需恢复本机工厂校准，先保留当前校准备份并阅读电台校准页面：设置→校准，SK2＋下键到恢复出厂页，在该页SK2＋绿键恢复本机工厂校准，不同时按SK1。该动作覆盖本地微调，不能当作每次升级的必要步骤；不确定时先提交Issue。
没有功率计／假负载时不要用热点BER盲调PA驱动；显示功率不是实测。
