# v1.2.0-rc.10 · C4FM 红键与来话显示 / C4FM Back key and caller display

- C4FM 主屏短按或长按红键时保持当前信道或 VFO，避免退回 FMN。红键仍可取消 DG-ID 输入、退出房间或位置页。用 **SK2＋短按 `*`** 切换工作模式。
- C4FM 和 DMR 共用彩色来话布局。两种模式的呼号字号、居中位置、底部信号条及 S 值／dBm 一致。C4FM 顶部显示实际接收的 DG-ID。
- 双段 MD‑UV380／MD‑UV390 的 5W＋GPS、10W PD8 和 10W PC6 均提供 `01 字库`、`02 拼音` 和 `03 主固件`，支持 C4FM DN 发射及随语音发送 GPS。两种 10W 的空口互通和功率仍待真机验证。

已有项目当前字库和拼音，只刷对应板型的 `03`。首次安装使用同一板型的 `01 → 02 → 03`。升级前备份码表和本机校准。

## English

- Tapping or holding RED on the C4FM main screen keeps the current channel or VFO. RED still cancels DG-ID entry and closes room or position pages. Use **SK2 + short `*`** to cycle radio modes.
- C4FM and DMR share the colour caller layout, including the callsign font and placement and the bottom S-meter with dBm. The C4FM header shows the received DG-ID.
- The dual-band 5W+GPS, 10W PD8 and 10W PC6 profiles each include Stage 01 font, Stage 02 pinyin and Stage 03 main firmware. Existing resources need only the matching Stage 03.

Host regressions and builds cover the software paths. Display behavior and RF on the radios remain to be verified.
