# v1.2.0-rc.16 · 多机型公测与 C4FM 频偏预置 / Multiple radio profiles and C4FM trim preset

[公测网站与机型选包 / Test site and package selector](https://xunyu5800-alt.github.io/OpenGD77-DIGIALL-Testing/) · [机型验收表 / Acceptance matrix](https://github.com/xunyu5800-alt/OpenGD77-DIGIALL-Testing/blob/main/docs/TEST_MATRIX.md) · [提交反馈 / Report a test](https://github.com/xunyu5800-alt/OpenGD77-DIGIALL-Testing/issues/new?template=firmware-test.yml)

- **DIGIALL 编译包**涵盖双段 MD-UV380／390 的三个板型，并新增 **RT-3S、DM-1701、RT-84**。每种板型都有独立 ZIP，内含字库、拼音、主固件和安装说明。
- **上游 OpenGD77 R20260131** 包涵盖 GD-77、GD-77S、DM-1801、DM-1801A、RD-5R、MD-9600／RT-90 的 V1／V2／V4／V5、MD-2017／RT-82，以及 OpenDM1701 对照。
- C4FM 收发构建的「信道详情 → 发射频率」短按 **SK1**，切换 **0／+300 Hz**。保存后应用，左右仍可 50 Hz 微调。预置不会替换已有设置，也不会调整 DMR、FM 或热点。+300 Hz 来源于一组实测，需按每台设备复测。
- 新增板型需真机验证。**DM-1701、RT-84 的 C4FM 发射关闭**。RT-3S 的 C4FM DN 收发亦待真机验证。各包使用自己的 CPS 入口。现有一次刷机向导继续适用于它所标明的 rc.15 固件。

分享这个发布页给测试者，按机背和实际板型选一个 ZIP。请先反馈能否正常开机、显示和响应按键，再检查 FM／DMR。 [中文安装与测试清单](https://github.com/xunyu5800-alt/OpenGD77-DIGIALL-Testing/blob/v1.2.0-rc.16/docs/MULTI_MODEL_TESTING.zh-CN.md)

## English

Six DIGIALL builds cover three TYT dual-band MD-UV380/390 profiles and new RT-3S, DM-1701 and RT-84 candidates. Each has a separate ZIP. The collection also includes original OpenGD77 R20260131 binaries for GD-77, GD-77S, DM-1801, DM-1801A, RD-5R, the four MD-9600/RT-90 board versions, MD-2017/RT-82, and an OpenDM1701 reference.

C4FM transmit-enabled builds offer a 0/+300 Hz preset on **Channel Details → TX trim → tap SK1**. Confirm the change with the usual save action. It keeps ordinary 50 Hz adjustment and leaves DMR/FM and hotspot calibration alone. The +300 Hz value is a test point from one radio/hotspot combination.

C4FM transmit is disabled on DM-1701 and RT-84. The new profiles require on-radio acceptance. Verify display, keypad, FM and DMR before testing digital features. Flash with the corresponding CPS loader and board-specific ZIP.
