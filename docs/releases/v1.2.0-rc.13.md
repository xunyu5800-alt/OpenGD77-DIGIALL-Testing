# v1.2.0-rc.13 · 本地时区显示 / Local time display

- 在「设置 → 显示设置」调整时区偏移时，自动将「时间」切到「本地」。时区已经设好的用户可以直接选择「时间 → 本地」，再按绿键保存。需要查看 UTC 时可以手动切回。
- 统一主屏、电台信息和通话日志的时区换算。西半球半小时和 15 分钟时区的菜单显示已修正。红键取消会恢复之前的时区和 UTC／本地选择。
- GPS 自动校时仍给 RTC 提供 UTC。显示时间按所选偏移换算。

双段 MD‑UV380／MD‑UV390 提供 **5W＋GPS、10W PD8、10W PC6** 三种板型。已装当前字库与拼音的电台只刷对应的 `03` 主固件。首次安装请按 `01 → 02 → 03`。

真机复测可将时区设为 `+8:00`，对照主屏、电台信息和通话日志，关机重开后确认显示正确。

## English

- Changing the offset under **Options → Display options → Timezone** selects **Local** automatically. If the offset is already set, select **Time → Local** and press GREEN. You can select UTC manually.
- The home screen, Radio info and call log share the display offset. The menu formats negative fractional offsets correctly. RED restores the previous offset and UTC/local choice.
- GPS sync continues to set the RTC in UTC. The selected offset is applied to the displayed time.

Packages cover dual-band MD‑UV380/MD‑UV390 **5W+GPS, 10W PD8 and 10W PC6**. With current font and pinyin resources installed, flash the matching Stage 03. For a first install, flash Stages 01 through 03 in order.

For on-radio verification, set an offset such as `+8:00`, compare the home screen, Radio info and call log, then confirm the display after a normal power cycle.
