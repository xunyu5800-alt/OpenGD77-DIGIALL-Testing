# v1.2.0-rc.17 · 可交互双守、三协议切换与瀑布图修复

**发布署名 / Release credit · VRWZI / BIAOQ**

- 双守固定上下 A/B 分区并增加边距。蓝 A、橙 B、箭头/PTT 操作侧、绿色 RX 和红色 TX 分开标识。来话期间频率位置保持稳定。
- 普通按键、改频、换信道和菜单设置不会结束双守。短红键选 A/B，旋钮调频/换信道；实体 PTT 在选中侧发射。**本版替换 rc.15 的 SK1=A／PTT=B 映射**，按住 SK1 查看收发频率和参数，松开恢复。
- SK2+* 在当前侧循环 FM → DMR → C4FM。两侧分别保留协议与 DG-ID，轮询时交接 PCM/DMA。模式切换统一刷新分屏，避免普通主屏覆盖；设置与 PTT 结束后恢复轮询。
- 修复非 FM 语音 PTT 后自动信标误弹 APRS: FM；不适用的自动信标静默跳过，手动发送保留模式检查。
- 重做瀑布图：独立绘制频率轴、SEL/MAX 频率、真实读数的三点中值、失败读数留空；切换中心频率不再插入时间界面。
- 保留 rc.16 的六种 DIGIALL 板型、刷机说明、C4FM 频偏预置及既有修复。两种 10W 保留 C4FM 收发；DM-1701/RT-84 仍关闭 C4FM 发射。未变化的上游对照包继续从 rc.16 下载。

已有项目字库和拼音只更新本机型 ZIP 内的 03 主固件。首次安装按 01→02→03，并等待资源写入完成与熄屏后关机。按实际板型选包，沿用 CPS 合法 donor 合入流程，公开包不含专有 codec。

软件回归、六板型的主固件/字库/拼音清理构建、ZIP 内外 SHA-256 与发布附件下载核对是软件验证；真机 LCD、RF、音质、BER 和跨协议漏收仍待验收。单接收机不能同时接收，C4FM 较长驻留会增加另一侧等待。

## English

Interactive A/B dual watch now keeps editing, channel changes and menu adjustments in the session. Red selects the pane, rotary tunes/selects channel, physical PTT transmits on that pane, and held SK1 shows details. This deliberately replaces rc.15's separate SK1=A / PTT=B mapping. SK2+* cycles FM/DMR/C4FM independently per pane; decoder ownership, DG-ID, menu and PTT return are preserved. Dedicated split rendering prevents ordinary-screen overlays.

The waterfall has measured median-of-three samples, missing-read gaps, frequency axes and SEL/MAX frequencies. Automatic APRS tails no longer show an FM-only rejection after digital voice. Retains all six rc.16 board profiles, 10W C4FM TX and trim preset; DM-1701/RT-84 remain C4FM RX only. Existing resources: stage 03 only. First installation: matching 01→02→03. Software and byte-readback checks are not on-radio acceptance.
