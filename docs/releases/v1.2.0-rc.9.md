# v1.2.0-rc.9 · 10W C4FM DN 发射公测 / 10W C4FM DN transmit preview

本版在双段 MD‑UV380／MD‑UV390 Plus 10W 的 PD8 和 PC6 两种板卡上启用主屏 C4FM DN 发射，支持语音、随语音发送 GPS，以及 Wires-X 房间指令。两种 10W 构建都沿用 10W 的功率档位和本机校准，按各自板卡设置背光及 PA 选择引脚。

| 硬件 | 背光／PA 选择 | rc.9 C4FM DN |
| --- | --- | --- |
| 普通 5W＋GPS | PD8／PC6 | 收发及 GPS |
| Plus 10W PD8＋GPS | PD8／PC6 | 收发及 GPS，真机公测 |
| Plus 10W PC6＋GPS | PC6／PD8 | 收发及 GPS，真机公测 |

## 安装与反馈

1. 核对实际板卡，备份码表和本机校准。已有项目字库、拼音时刷对应 `03`，首次安装使用相同板型的 `01 → 02 → 03`。按原 CPS 声码器合入流程安装。
2. 用 **SK2＋短按 `*`** 切换到 C4FM。在匹配频率和 DG-ID 的另一台 DN 接收机或热点上监听。第一次建议选 **250 mW**，短按住 PTT 讲话约 2 秒。核对是否收到呼号和清晰语音、松键是否恢复接收。
3. 已定位时可在「信道详情 → 发送GPS」开启坐标测试。请反馈板型、固件包、频段、功率档、接收机或热点、语音和 GPS 结果，有 BER 日志可一并提交。

两个 10W 镜像已编译，主机回归覆盖功率档映射、PTT、GPS 和收尾。两种板卡的真机空口互通、实际功率、长发温升及 BER 待测试。功率档位为标称值。

## English

Both 10W Plus PCB layouts now enable main-screen C4FM DN PTT, voice GPS, and Wires-X commands. They use the existing 10W power calibration and their own PA-select and backlight pin assignments. GPS Tx defaults to Off and requires a fresh fix.

Choose the matching PD8 or PC6 Stage 03 package. Start on the lowest practical power, preferably the nominal 250 mW setting, and send a short voice call to a matching DN receiver. Check callsign, speech, return to RX, and optional GPS. Include the exact board, package, band, power setting, receiver, and any BER in test reports.

Both 10W variants are hardware-test builds. RF interoperability, output power, thermal behavior and BER remain to be verified on radios. Public packages include no donor or proprietary AMBE image.
