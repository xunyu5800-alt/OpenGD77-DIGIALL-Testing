# v1.2.0-rc.19 — DM-1701／RT-84 启用 C4FM DN 发射

DM-1701、RT-84 从主屏按实体 PTT 发送 C4FM DN 语音，松开后结束发射并恢复接收。之前 rc.16–rc.18 的构建配置将这两种板型排除在 C4FM 发射之外；本版移除该排除项，六种 DIGIALL 板型均编入 C4FM DN 收发。FM／DMR 的原有收发和信道“仅接收”、PTT 锁、超时、硬件故障停发保护保留。此版本是公测，C4FM 射频、音频与 BER 仍待对应实机验证。

补齐 DM-1701／RT-84 的 C4FM 50 Hz 频偏标志位与双守 A/B 保存恢复，详情页使用实际板型设置定义验证，避免切换后丢失半步频偏。

保留 rc.18 的 DM-1701 160×120 屏幕适配、双守 APRS 位置弹窗和 A/B 交互、瀑布图修复。网站选包器可检查最新版本，切回标签页时保留机型并更新下载地址；脚本、样式和初始目录使用内容校验命名，减少旧版本缓存。

**ZIP 不能直接刷入电台。先解压，CPS 每次只选择一份 BIN。完整安装按 01_font → 02_pinyin → 03_main 分别刷写三次，每次重新进入 DFU。** 01／02 写入后正常开机运行写入器，看到 COMPLETE - VERIFIED、等待背光熄灭后关机；出现 FAILED 时停止。最后必须刷 03_main。已确认兼容字库和拼音完整的项目固件升级，可只更新对应机型的 03_main。误刷 ZIP 或停在写入器后循环重启时，重新进入 DFU 完成三步。

六种机型独立 ZIP 均附安装说明、三个 BIN 和 SHA-256；十一种未变更的上游参考包沿用 rc.16。按实际板型选包，数字语音沿用 CPS 合入自己的合法 donor；公开包不含专有声码器。

DM-1701 and RT-84 now compile main-screen C4FM DN PTT, matching the other four DIGIALL profiles. RX-only channels, PTT lock, timeout and hardware-failure TX guards remain. Hardware RF/audio/BER acceptance is pending. Retains rc.18 dual-watch APRS and DM-1701 display fixes. Extract ZIPs and flash BINs individually. Full installation: 01_font → 02_pinyin → 03_main, re-entering DFU for each stage; run both resource writers to COMPLETE - VERIFIED before switching off. Existing verified compatible resources: update matching 03_main only.
