# v1.2.0-rc.18 — 双守 APRS 弹窗与三步安装说明

修复双守下已解码 APRS 位置只留后台记录、不显示卡片的问题：另一侧已切到 DMR/C4FM 仍可提示。卡片显示 5 秒，超时或短按红键后恢复双守，保留原 A/B 配置和选中的 PTT 侧。排队位置不再被其他台站的非位置报文清掉；按键、输入、锁定、发射和回放仍会延后提示。

修复 DM-1701 的 160×120 有效屏幕适配：双守恢复大频率、来话、TG/TS/CC 与发射信息；压缩行距并保留边距。APRS/数字位置页的经纬度和底部提示按实际屏高排列，避免最底部裁切。增加 160×120 下的文本重叠、边界和双守恢复检查；这是软件渲染验证，不是真机 LCD 照片。

**ZIP 压缩包不能直接刷入电台。先解压，CPS 每次只选择一份 BIN。完整安装必须分别刷写三次：**

1. 进入本机 DFU，刷 `01_font_*.bin`；正常开机运行字库写入器，看到 `COMPLETE - VERIFIED`、等背光熄灭后关机。
2. 重新进入 DFU，刷 `02_pinyin_*.bin`；正常开机运行拼音写入器，看到 `COMPLETE - VERIFIED`、等背光熄灭后关机。
3. 再次进入 DFU，刷 `03_main_*.bin`；完成后松开按键正常开机。

资源写入显示 FAILED 时停止。01/02 是临时写入器，不能作为最终运行固件。误刷 ZIP 或停在写入器后循环重启时，关机重新进入 DFU，完成全部三步，最后必须刷 03_main。已确认兼容字库和拼音完整的项目固件升级可以只更新 03_main。按实际板型选包，数字语音沿用 CPS 的自有 donor 合入流程。

六种 DIGIALL 板型各含 01/02/03 和根目录安装必读，保留 rc.17 的双守交互、瀑布图和机型能力。5W、两种 10W、RT-3S 保留 C4FM 主 PTT；DM-1701/RT-84 仍为 C4FM 接收。十一种上游参考包沿用已有版本。

软件验证包括 APRS 弹窗、混合协议、排队报文、超时/锁定/输入保护、两种屏幕尺寸与双守恢复。构建、发布字节校验不代替电台 LCD、射频、音频实测。

Do not flash ZIP archives. Extract the package, then flash 01_font, 02_pinyin and 03_main separately in that order, re-entering DFU each time. Run resource writers to COMPLETE - VERIFIED before switching off. Always finish full installation with 03_main. This release restores queued APRS position popups during mixed-mode dual watch and preserves the selected PTT side on return. Hardware validation remains pending.
