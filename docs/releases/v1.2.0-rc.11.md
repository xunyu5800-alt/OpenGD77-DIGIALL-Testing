# v1.2.0-rc.11 · APRS 坐标与手动校时 / APRS positioning and manual clock

- APRS「位置 → GPS」在发射时取近期有效定位。CPS 固定坐标用于「位置 → 信道」。普通报文的纬度或经度在分钟四舍五入时会正确进位。
- 「菜单 → 电台信息」可输入 8 位日期 `YYYYMMDD` 或 6 位时间 `HHMMSS`，按绿键保存。手动保存会关闭 GPS 校时，GPS 定位仍可用。可在「设置 → 通用设置 → GPS 校时」重新开启校时。
- 主屏和电台信息使用相同的本地／UTC 设置。北京时间请选择本地时间，时区设为 `+8:00`。

双段 MD‑UV380／MD‑UV390 有 **5W＋GPS、10W PD8、10W PC6** 三种包。已有项目当前字库和拼音，只刷匹配的 `03` 主固件。首次安装请按对应板型的 `01 → 02 → 03` 顺序。

真机验收请对照手台 GPS 数值和接收端原始 APRS 报文，核对时将 CPS 位置模糊度设为 0。另请确认正常关机再开机后手动时间继续走动。

## English

- APRS **Location → GPS** uses a fresh fix at send time. The CPS fixed position applies to **Location → Channel**. Uncompressed coordinates now carry rounding into the degree field correctly.
- On **Menu → Radio info**, enter an eight-digit date (`YYYYMMDD`) or six-digit time (`HHMMSS`) and press GREEN. A manual save disables GPS clock sync and leaves GPS positioning available. Re-enable sync at **Options → General options → GPS Clock Sync**.
- The home screen and Radio info share the UTC/local display setting.

Packages cover dual-band MD‑UV380/MD‑UV390 **5W+GPS, 10W PD8 and 10W PC6**. If the current font and pinyin resources are installed, flash the matching Stage 03 only. For a first install, use Stages 01, 02 and 03 in order.

For on-radio testing, compare the GPS reading with the received APRS packet at zero CPS ambiguity, then check that manual time continues after a normal power cycle.
