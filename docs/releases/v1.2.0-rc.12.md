# v1.2.0-rc.12 · APRS 四位坐标与默认设置 / Precise APRS and radio defaults

- CPS 位置模糊度为 `0` 时，普通 APRS 位置报文通过标准 `!DAO!` 扩展发出北纬／南纬和东经／西经的附加精度。支持该扩展的接收端可还原四位十进制度小数。压缩报文使用 Base‑91。
- 手台新建的 APRS 配置默认为位置模糊度 `0`。从 CPS 导入的已有配置保留各自的数值。
- 首次初始化或恢复设置默认开启 GPS 自动校时，自动背光超时为 **30 秒**。升级沿用已保存的校时和背光选择。

双段 MD‑UV380／MD‑UV390 提供 **5W＋GPS、10W PD8、10W PC6** 三种板型。已装本项目当前字库和拼音时，只刷匹配的 `03` 主固件。首次安装按 `01 → 02 → 03`。

真机复测可用 CPS 模糊度 `0`、关闭 APRS 压缩，在 GPS 定位后用 **SK1＋2** 发一包，对照原始报文的 `!w…!`、接收端还原结果和手台坐标。

## English

- At zero CPS position ambiguity, uncompressed APRS beacons carry the standard `!DAO!` extension. Receivers that support DAO can recover four decimal places of latitude and longitude in degrees. Compressed beacons use Base‑91.
- APRS profiles created on the radio default to zero position ambiguity. Existing profiles keep their CPS values.
- Initial or reset settings enable GPS clock sync and use a **30-second** automatic backlight timeout. Upgrades retain saved clock and backlight choices.

Packages cover dual-band MD‑UV380/MD‑UV390 **5W+GPS, 10W PD8 and 10W PC6**. With current font and pinyin resources installed, flash the matching Stage 03. For a first install, use Stages 01 through 03.

For on-radio verification, set CPS ambiguity to zero, disable APRS compression, and send a beacon with **SK1 + 2** after a GPS fix. Compare the `!w…!` packet as decoded by the receiver with the radio's GPS reading.
