# 中文输入与资源安装

安装按[使用说明](USAGE.zh-CN.md)进行。已有本项目资源只刷03；首次或R250326旧资源按匹配硬件01→02→03。


1. 进入信道详情/联系人详情的“名称”，或电台配置中的新建信道、分区名称、五音联系人名称。
2. 按 **SK2 + #** 进入拼音模式；底部出现 `PY:` 与候选行。同一组合键退出，返回原有英文输入。
3. 用原有数字键多击输入字母：2=abc、3=def、4=ghi、5=jkl、6=mno、7=pqrs、8=tuv、9=wxyz。输入 `zhong` 等拼音，不带声调；`ü` 用 `v`。
4. 左右选择候选，上下翻页；在这类菜单中，旋钮对应左右选择，前面板上下键翻页。按绿键插入当前汉字。
5. 可继续输入下一个拼音。红键退一位拼音；拼音为空时红键退出拼音模式。
6. 完成后按 SK2 + # 退出拼音，再按原编辑器的保存方式保存：例如信道详情的 SK2 + 绿键。拼音模式中的绿键只选字，不会直接保存整个名称。

例如输入 `zhong` 选择“中”，再输入 `guo` 选择“国”。下方计数表示候选页数。达到 16 字节上限后不会插入半个汉字；先删除部分名称再继续。普通名称中的中文光标移动、删除和中英文替换也按完整 GB2312 字符处理。


资源占用外部Flash最后512KiB，不兼容R250326旧资源格式。名称为16字节，最多8个汉字；拼音仅提供单字候选。安装前备份记录和本机校准。
