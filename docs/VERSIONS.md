# Test releases / 测试版本

Current: [v1.2.0-rc.6](https://github.com/xunyu5800-alt/OpenGD77-DIGIALL-Testing/releases/tag/v1.2.0-rc.6).
Free non-commercial binary test distribution. Source and development history remain private; this repository contains no firmware source code.
当前为免费非商业二进制测试发布；源码与开发历史保持私有。本仓库不含固件源码。

5W: FM/DMR plus C4FM DN main-screen RX/TX. Both10W profiles: C4FM RX only.
当前5W支持主屏C4FM DN收发；两种10W布局仍为C4FM仅接收。
rc.6 adds automatic CPS-frequency APRS reception, hold-`#` priority watch, shared caller position pins and a short-PTT C4FM end-frame fix. Repeater white noise still requires hardware retesting.
rc.6 增加CPS频率APRS自动接收、长按 `#` 优先守候、数字来话统一位置图钉，并修复C4FM短按收尾；中继白噪声仍需真机复测。
Public packages preserve the official rc.6 firmware binaries byte-for-byte; public documentation and ZIP checksums differ from the private development release.
九份固件二进制与官方rc.6构建逐字节一致；公开文档及ZIP校验值不同。
