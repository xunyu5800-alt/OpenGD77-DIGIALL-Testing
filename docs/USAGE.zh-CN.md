## 1. 选择正确固件

仅用于下表中的**双段 MD-UV380／MD-UV390**，不能刷入单段 MD-380／MD-390。

| 硬件 | 包名包含 | 背光／PA |
| --- | --- | --- |
| 普通 5W＋GPS，本次已确认的测试机 | `MD_UV380_UV390_5W_GPS` | PD8／PC6 |
| Plus 10W，经确认的 PD8 板卡 | `PLUS_10W_PD8_GPS` | PD8／PC6 |
| Plus 10W，经确认的 PC6 板卡 | `PLUS_10W_PC6_GPS` | PC6／PD8 |

10W 不能仅凭机壳名称判断板卡。三个构建均启用 C4FM DN 主屏收发及 GPS，两种 10W 仍待真机验证。GPS 功能需要实际 GPS 硬件。

若按 PTT 提示「仅接收」，检查当前信道的「信道详情 → 仅接收」，并核对已安装的 03 包版本和板型。rc.8 的 10W 包只开放 C4FM 接收。

## 2. 安装或升级

1. 使用 CPS 备份码表、**本机校准**及需要的记录，保存原可用固件和恢复方法。
2. 从对应 Release 下载与硬件匹配的 ZIP，可用 `SHA256SUMS.txt` 检查文件完整性，解压后阅读包内 `INSTALL`。
3. **已安装本项目当前字库与拼音：只刷匹配的 `03` 主固件。** 首次安装或仍使用 R250326 的旧资源：同一硬件、同一版本依次刷 `01 字库 → 02 拼音 → 03 主固件`。
4. 每个资源写入器刷入后正常开机，等待 `COMPLETE - VERIFIED` 和熄屏，关机再进行下一步。若出现失败，先停止后续刷写并核对包名。
5. 主固件沿用 CPS Firmware Loader 与相应声码器合入流程。公开包不含 AMBE／donor；自行取得和使用须具有相应权利，不转载合入后的固件。
6. 首次资源安装后可按住 **SK1＋数字 5** 开机检查，成功提示 `CJK data OK / log reset`。资源占用外部 Flash 最后 512KiB，安装前备份需要的记录；不要混用旧版资源。

升级不会自动修正以前错用 10W 包所生成的本地校准。没有可靠备份时不要导入别台机器的校准，按[5W 安装与校准说明](MD_UV380_5W_GPS.zh-CN.md)处理；其中旧包名属历史记录，新包名以当前 Release 为准。资源操作细节见[中文输入](CHINESE_INPUT.zh-CN.md)，日常功能以本说明和当前 Release 为准。

## 3. 常用操作与 DMR

| 操作 | 行为 |
| --- | --- |
| SK2＋短按 `*` | FM → DMR → C4FM → FM |
| 实体 PTT | 在允许发射的模式、信道和页面发射；松开停止 |
| SK2＋机身上下键 | 调整功率，沿用全局／信道设置与校准；显示瓦数不是实测值 |
| DMR 来话时机身上下键 | 切当前接收组列表中的 TG，丢弃旧组的接收音频 |
| DMR 长按 SK1 | 切换并保存 `ALL` 全部目的组／`TG` 当前指定组过滤 |
| DMR 短按 SK1，或长按 `0` | Finder 全搜索；绿键锁定所选 TG／CC／TS，红键恢复进入前配置 |
| DMR 橙键快捷菜单 | 可选择 `TGL` 接收组列表过滤 |
| 数字主屏长按绿键 | 查看当前来话位置／距离／指南针，红键返回 |

`TG` 是当前指定组，`TGL` 是接收组列表，`ALL` 放行全部目的组；CC／TS 仍按独立设置处理。顶部 `RX TG91 [ALL]` 表示实际收到 TG91，下方 `TX TG:9` 表示当前选定发射 TG9，两者可以不同。不会因为看见别组来话就自动修改自己的发射目标。详见[过滤与切组说明](DMR_LIVE_TG_FIX.zh-CN.md)。

### VFO 双守候

FM／DMR VFO 默认在 A／B 间轮流接收。长按红键选调频主路，单独长按 SK1 发 A，实体 PTT 发 B。按住 SK1 再长按绿键切换单守／双守。DMR 长按 SK1 切 ALL／TG 适用于单守，双守可从快捷菜单切过滤。

### 设置手台日期和时间

进入 **菜单 → 电台信息**，用机身上下键找到「日期」或「时间」。日期直接输入 8 位 `YYYYMMDD`，时间输入 6 位 `HHMMSS`，分别按绿键保存。

使用北京时间时，在 **设置 → 显示设置** 将「时区」设为 `+8:00`。调整偏移时会自动切到「本地」。如果时区已经设好，可直接将「时间」设为「本地」并按绿键保存。要显示 UTC，可在同一菜单将「时间」选回 UTC。

手动保存后，GPS 校时会切换为关闭，GPS 定位仍可使用。要恢复自动校时，在 **设置 → 通用设置 → GPS 校时** 选择开启，再按绿键保存。

新装或恢复设置默认开启 GPS 校时，自动背光超时为 30 秒。升级保留已经保存的手动校时及背光选择。

## 4. C4FM 日常收发（普通 5W）

从主屏使用 PTT，不必停留在 `4:MIC` 高级测试面板。接收默认使用 RAM 路径。主屏上下键选择 DG-ID 0～127，短按 `*` 输入 DG；绿键确认、红键取消。短按 SK1 临时搜索所有 DG，长按 SK1 保存 ALL／指定过滤。SK2＋上下沿用 DMR 的功率档位。

- **设置**：SK2＋绿键或长按 `*` 打开共用信道详情，旋钮选项、机身上下调值，绿键保存、红键取消。C4FM 的 DG、过滤及独立 TX 微调在此设置；CC／TS 不是 C4FM 参数。
- **房间**：短按 `#`（或 SK2＋`#`）打开房间页，打开页面不会自动发射；`#` 查询，输入五位房间号后按绿键连接，长按 `*` 断开。只有收到并核验回复后才显示连接结果；超时不能当作已连接。
- **诊断**：SK1＋短按 `#` 切换主屏／接收诊断／健康页；诊断页绿键切 RAM／I2S，7／9 调接收播放增益。日常接收优先使用已验证较好的 RAM。
- **发射时限**：主屏采用信道 TOT；TOT=0 时回退 60 秒。高级测试仍有单独限制。松开 PTT 后完成受限结束过程，故障会停发。

异频示例：热点 `RX=433.950MHz、TX=439.950MHz` 时，手台应设 **RX=439.950MHz、TX=433.950MHz**。SDR 录制中心频率不等于手台发射频率，不能混为一项设置。

调试基线为 D22／INV／G4／N2／E1；它来自当前 5W 测试机，不能保证适用于所有机器。热点 RXOffset 会影响多个模式，先保留 DMR 可用的值；必要时单独调整手台 **C4FM TX 微调**，默认 0，不改 FM／DMR 或工厂校准。不要把某次 BER 最佳值当作通用校准。[完整 C4FM 操作](C4FM_OPERATING.zh-CN.md)

### YSF2DMR 桥接

Pi-Star 启用 YSF、YSF2DMR 并应用，在 Yaesu System Fusion Configuration 区域配置本人有效 DMR ID、目标主站、Hotspot Security 与目标 TG；启动主机选 **00002／Link YSF2DMR**。密码留在热点本机，不放进截图或公开日志。

**DG-ID 0 不等于 DMR TG。** 目标 TG 由桥接端设置；五位 YSF 房间号也不是六位 DMR TG。测试本机 YSF2DMR 桥时不要再通过房间页连接其他反射器。用独立接收端／Hoseline 验证真实交付，手台本地回声不能证明上行已进目标 TG。[桥接排查](C4FM_NETWORK_ECHO.zh-CN.md)

## 5. GPS、APRS 与位置图钉

要发送实时定位，在 **设置 → APRS → 位置** 选择「GPS」，等手台定位有效后再发送。需要发固定台址时选择「信道」，优先取 CPS 固定坐标，未配置时可使用电台保存的位置。

在 **菜单 → 电台配置 → APRS 设置** 选择信道所关联的配置，找到「模糊度」，用左右键调整，选择「保存」。新配置默认为 `0（完整）`。其余档位按十进制度步长显示，分别为 `0.0002°`、`0.001°`、`0.002°`、`0.01°`、`0.02°`、`0.1°`、`0.2°`、`1°`。例如 `0.01°` 按两位十进制度小数发送。这个值与 CPS 的位置模糊度共用。

本版使用 APRS `!DAO!` 扩展为普通报文补足精度，支持该扩展的接收端可还原四位十进制度小数。压缩报文直接用 Base‑91 表示高精度坐标。[APRS 精度扩展](https://www.aprs.org/aprs12/datum.txt)

GPS 新装默认开启，手动关闭后会保存；在 GPS 菜单检查卫星与定位，模块开启不等于已定位。Flash 轨迹记录与 GPS 开启是不同功能，当前不启用 GPS Flash 轨迹。

APRS 后台解码**当前 FM 频率**的音频，须调到当地合法使用的 APRS 频率；它不能在守听 DMR／C4FM 或其他频率时同时接收 APRS。单接收机没有跨频后台守听能力；省电、录音及占用音频的功能可能影响解码，见[GPS／APRS 限制](GPS_APRS.zh-CN.md)。

- APRS 收到有效位置包后，在允许的空闲状态自动打开位置卡片，5 秒后返回原页面。从日志用绿键手动打开时可一直查看，左右切换位置／文本，红键返回。
- APRS 日志保存最近 16 条记录，满时替换最旧的未收藏条目。按住 SK2 短按 `#` 收藏或取消收藏，呼号前的 `*` 表示已收藏。单独短按 `#` 只清除未收藏记录。
- 呼号旁的**图钉**表示有有效接收坐标，不依赖本机 GPS 是否定位，也不保证位置是实时的。DMR／C4FM 新版来话页、DMR 最近收听和 APRS 列表均有提示。
- DMR／C4FM 保留来话主屏，**长按绿键**查看位置。最近收听选中带图钉呼号长按绿键，查看标为 `LAST` 的历史位置；短按绿键仍选组。
- 页面显示对方经纬度；有本机有效实时 GPS 或保存位置时，计算距离、初始方位与北向指南针。没有本机参考点仍显示对方坐标，不虚构距离。北向箭头不是机身磁罗盘。[位置页及示例图](RECEIVED_POSITION.zh-CN.md)

## 6. 中文、扫描、录音和其他功能
