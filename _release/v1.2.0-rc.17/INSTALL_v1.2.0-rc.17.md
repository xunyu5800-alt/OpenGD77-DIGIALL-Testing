# rc.17 安装与操作 / Installation and controls

发布署名 / Release credit: VRWZI / BIAOQ

按实际板型选择一个 DIGIALL ZIP，不要跨机型刷写。包内含 01 字库、02 拼音和 03 主固件；已安装项目资源的机器只更新 03。首次安装按 01→02→03，资源写入完成并熄屏后再关机。沿用 CPS 合法 donor 合入流程；公开包不含 codec 或 donor。

双守：短红键选 A/B；旋钮调频或换频道；SK2+* 循环 FM/DMR/C4FM；按住 SK1 查看当前侧详情；实体 PTT 在箭头选中侧发射；长红键退出。本版替换 rc.15 的 SK1=A / PTT=B 映射，SK1 恢复详情用途。菜单与设置结束后恢复双守。长 C4FM 驻留会延长另一侧等待，单接收机可能漏收短呼叫。

Select the exact board ZIP. Existing project font/pinyin: update stage 03 only. First installation: 01→02→03. Keep the CPS lawful-donor workflow; no proprietary codec is distributed. Red selects A/B; rotary tunes/selects channel; SK2+* cycles protocols; hold SK1 for details; physical PTT transmits on the selected pane; hold red to exit. This replaces rc.15's separate SK1/PTT transmit mapping.

继承 rc.16 的六种板型和 10W C4FM 收发；DM-1701/RT-84 仍关闭 C4FM 发射。未重新发布的十一种上游参考包继续使用 rc.16。主固件与资源均为清理构建，软件回归与摘要核对通过；真机 LCD、空口、音质和 BER 待验收。

Retains all six rc.16 board profiles and 10W C4FM TX; DM-1701/RT-84 remain C4FM RX only. Unchanged upstream reference packages remain in rc.16. Hardware RF/LCD/audio/BER acceptance is pending. See GUIDES and per-board README and licences.
